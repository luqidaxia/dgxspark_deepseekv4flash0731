## 说明

1. 输入长度使用字符数近似 token 数（中文每字符约 1 token）。
2. TTFT 从请求发出到收到第一个内容 token 的 SSE 数据包计算。
3. TPS 仅统计生成阶段：生成 token 数 / 首个内容 token 到最后一个 token 的时间。
4. 聚合吞吐 = 该 cell 内所有请求成功生成 token 总数 / 该 cell 总耗时。
5. 测试使用 streaming 模式，更贴近真实交互场景。
